# 牛币 NIU：项目介绍与安装指南

*一部粗糙的电影，点燃了一个荒唐的念头。这个念头，变成了一枚同样粗糙、但真实可运行的数字货币。*

本文分两部分：**上半部介绍这个项目是什么、为什么做**；**下半部是从下载到挖矿的完整安装步骤**，面向没有任何技术背景的朋友。如果你只想尽快上手，直接从[第二部分](#第二部分安装指南)开始。

# 第一部分：项目介绍

## 一个普通人的数字货币实验

比特币、密码学、分布式网络——这些东西听起来只属于顶尖程序员。我们习惯了观看，习惯了觉得"创造一件东西的资格，只属于那些已经掌握了全部知识的人"。

但一件事情不需要在开始时就完美，也有机会被真正创造出来。

牛币（NIU）就是这样开始的：一台电脑、一些零散的知识、AI 工具，和一种近乎固执的好奇心。不为融资，不为暴富，没有宏大的商业计划——只是想知道，**如果一个普通人从零开始创造一枚数字货币，究竟会发生什么。**

于是有了这条独立的小链，和这个你即将安装的钱包。它粗糙、甚至有些山寨，但第一个区块真实地诞生过，挖矿奖励真实地累计过，每一次"从无到有"的喜悦都是真实的。

## 牛币是什么

一句话：**一条跑在你自己电脑上的独立小区块链，配上一个普通人也会用的跨平台桌面钱包。**

| 项目 | 说明 |
|---|---|
| 项目名称 | 牛币 / 牛链（NIU） |
| 代币符号 | NIU |
| 网络类型 | 独立区块链（不是任何现有链上的代币） |
| 节点软件 | 基于 Core-Geth v1.12.23 修改 |
| 共识机制 | Ethash 工作量证明（PoW），目标出块约 60 秒 |
| 智能合约 | 支持 London EVM / Solidity |
| 初始区块奖励 | 每块 1000 NIU，每 105 万块减半 |
| 小数位数 | 18 位 |
| 钱包平台 | Windows 10/11 x64、macOS Apple Silicon；两端使用相同 Electron 界面（无需浏览器） |
| 界面语言 | 简体中文、English、日本語、한국어、Español、Русский |
| 密钥保护 | Windows DPAPI 本机加密 + 密码加密的可携带备份 |
| 源代码 | https://github.com/yuanhong792/niu-wallet （公开） |

## 钱包能做什么

- **概览**：金币总余额、默认收款地址、区块高度、节点连接与挖矿状态，右下角有狗币式的**网络信号格**——已连接（满格+对勾）、正在同步、未连接，一眼看清网络状态。
- **接收**：生成自己的收款地址和二维码，可新增多个收款地址。
- **发送**：选择账户、填地址和金额、核对确认；带地址簿。
- **挖矿**：一键开启/停止 Ethash 挖矿，奖励自动计入钱包。
- **智能合约**：部署 Solidity 合约、更新链上留言（"慢慢来，也很牛。"）。
- **备份与恢复**：密码加密的备份文件，支持导入恢复；换电脑迁移就靠它。
- **多语言**：六种界面语言即时切换。

## 我们做什么，不做什么

说实话，比说得漂亮更重要。

**我们在做的：**

- 从代码层面理解并实现一条完整的小区块链：区块、哈希、挖矿、交易、钱包、节点。
- 记录普通人借助 AI 学习编程、排查问题、开发区块链程序的真实过程。
- 开放交流：欢迎懂技术的朋友指出问题，也欢迎刚入门的朋友一起学习。
- 探索真实但不过度承诺的方向：教学演示、测试网络、AI 智能体自动化微支付实验。

**我们不做的：**

- **不承诺币价**。这枚币目前没有市场、没有交易所、没有实际购买力。
- **不虚构生态**。不会为了让白皮书看起来宏伟而许诺无法兑现的未来。
- **不碰你的私钥**。项目方无法找回你的密码，也不会索取你的私钥、备份密码或 runtime 文件夹。
- **不回避不完美**。程序未签名、未经第三方安全审计，**不适合存放有实际价值的资产**。请把它当作学习实验，而不是投资品。

技术需要验证，观点允许讨论，问题应该被公开提出。我们可以允许第一个版本非常粗糙，但不能因为它已经运行起来，就假装它已经成熟。

# 第二部分：安装指南

## 准备工作

- 一台 **Windows 10 或 11（64 位）** 电脑
- 磁盘剩余空间 **不少于 3 GB**（压缩包约 122 MB，解压后含节点程序约 2.4 GB）
- 能上网（首次下载；钱包本身在本机运行，联网用于节点互联）

## 第 1 步：下载

1. 打开发布页：**https://github.com/yuanhong792/niu-wallet/releases**
2. 找到最新版本 `NIU Wallet v0.3.8 - macOS arm64 + Windows x64`。
3. 下载两个文件：
   - `NIU-Wallet-v0.3.8-Windows-x64.zip`（Windows 钱包）
   - `NIU-Wallet-v0.3.8-Windows-x64.zip.sha256`（Windows 校验文件）

> **如何确认下载到的是最新版？** 打开钱包后看两处：概览页**右下角有信号格图标**；设置页有**「导入钱包备份」按钮**。这两处是 2026-10-16 晚间更新的新版标志。

## 第 2 步：校验完整性（可选，推荐）

在 zip 所在文件夹打开 PowerShell，执行：

```powershell
certutil -hashfile NIU-Wallet-v0.3.8-Windows-x64.zip SHA256
```

把输出的哈希与 `.sha256` 文件里的内容对比，一致则文件完好，不一致请重新下载。

## 第 3 步：完整解压

1. 右键 zip → **全部解压缩**，选一个固定位置，例如 `D:\NIU-Wallet\`。
2. **务必保留完整目录**：`engine`、`bin`、`node`、`assets`、`scripts`、`node_modules` 等文件夹都是程序组件，**不要只把 NiuWallet.exe 单独复制出来**——那样钱包无法启动。
3. 解压完成后，进入文件夹，找到 `NiuWallet.exe`。

> 建议右键 `NiuWallet.exe` → 发送到 → 桌面快捷方式，以后从桌面打开更方便。

## 第 4 步：首次运行

1. 双击 `NiuWallet.exe`。
2. Windows 会弹出 **SmartScreen 蓝色提示**"已保护你的电脑"（因为程序未做签名）。点击 **「更多信息」→「仍要运行」**。
3. 钱包启动后会自动做三件事：启动本机节点、创建你自己的钱包账户、读取加密钱包文件。窗口底部会显示进度，看到 **「钱包节点已就绪」** 即启动完成。
4. 首次启动会为你生成自己的收款地址（在"接收"页可以看到）。

> 首次启动需要初始化节点，可能等待十几秒到一分钟，属正常现象。

## 第 5 步：认识界面

| 位置 | 内容 |
|---|---|
| 左侧栏 | 概览、发送、接收、交易记录、设置 |
| 概览页 | 金币总余额、默认挖矿地址、区块高度、节点连接、挖矿状态、最近记录 |
| 右下角 | **网络信号格**：满格+对勾=已连接；部分格+同步中=正在同步；灰格=未连接 |
| 底部状态栏 | 节点就绪状态、操作进行中的提示 |

## 第 6 步：开始挖矿

1. 进入「设置」页，确认**默认挖矿地址**是你的地址（默认就是）。
2. 在概览页点 **「开启挖矿」**。
3. 挖矿状态变为"进行挖矿"后，节点开始计算工作量证明，每挖到一个区块（平均约 60 秒一个），**1000 NIU** 奖励自动计入你的钱包，"最近记录"会出现一笔收入。
4. 不用时点「停止挖矿」即可。挖矿在本机进行，关闭钱包即停止。

> 提示：挖矿会让电脑风扇转起来、耗电增加。挂着玩的实验链，量力而行。

## 第 7 步：备份（最重要的一步）

**钥匙和账本都在你这台电脑上，备份是你唯一的后悔药。**

1. 进入「设置」页，点 **「保存加密备份」**。
2. 设置一个**至少 12 位**的独立密码（与钱包口令不同）。系统会加密并回读校验。
3. 把备份文件（`.json`）保存到 U 盘或另一块硬盘，**密码记在纸上，文件和密码分开保管**。
4. 文件和密码缺一不可，**丢失后任何人（包括项目方）都无法帮你恢复**。

**换电脑 / 重装系统后恢复**：在新电脑解压钱包，首次启动时选择"恢复备份"；或在「设置」页点 **「导入钱包备份」**，选择备份文件并输入密码即可。导入只新增当前钱包没有的地址，不会覆盖已有数据。

## 常见问题

**Q：双击后 Windows 拦截"未知发布者"？**
正常现象，程序未签名。点"更多信息"→"仍要运行"。

**Q：概览一直显示"连接中…"？**
等节点就绪（底部状态栏会提示）。朋友测试版已预置引导节点，若长时间无连接，联系发放者检查服务器。

**Q：余额显示 0？**
新钱包本来就是 0。老钱包若突然变 0，请保持钱包开着，程序会自动检测并恢复链头（新版已内置此功能，恢复成功/失败都会明确提示）。

**Q：怎么确认自己用的是最新版？**
看概览页**右下角有没有信号格**；设置页有没有**「导入钱包备份」按钮**。没有就是旧版，去 Releases 页重新下载。

**Q：可以删除 runtime 文件夹吗？**
**绝对不要。** 那里面是你的钱包文件、链数据和账本，删了币就没了（除非你有备份文件+密码）。

**Q：转账后对方多久收到？**
交易需要网络持续出块才能确认。实验链上请耐心等待确认数增加。

**Q：这币值钱吗？能交易吗？**
目前不能。它是一枚学习实验币，没有市场、没有交易所、没有购买力。我们如实告诉你，也请你如实告诉朋友。
