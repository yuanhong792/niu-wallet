## 摘要｜一枚币的诞生，和一条链的边界

牛链（NIU）是一项由个人动手实践、借助 AI 辅助学习与开发的独立区块链实验。它采用基于 Core-Geth 修改的账户式区块链，使用 Ethash 工作量证明、London EVM 执行环境，并提供 Windows 桌面钱包，使参与者可以创建地址、收款、转账、主动挖矿、部署与调用示例智能合约。NIU 为链上的原生资产，用于价值转移与支付 Gas。

本白皮书同时回答两种问题：为什么一个普通人愿意为一枚目前没有市场价值的币投入数日，以及这枚币在技术上究竟实现了什么、还有什么没有实现。项目已经有本机实验验证和公开代码，但尚不能表述为完成公网主网启动、第三方审计或稳定商业运行。

## 第一章｜那部粗糙的电影

事情的起点并非交易行情，也非融资计划。前几天，我看了牛来的一部电影。画面很粗糙，制作甚至有些简陋，但它竟然真的走进了电影院。看着屏幕，我忽然想到：一件东西在诞生之初，或许不必先达到世人眼中的完美，才有资格被做出来。

以前我总认为数字货币距离普通人很远：比特币、哈希、矿工、分布式账本、密码学，每一个词都像是一道门槛。我们习惯于使用技术、谈论技术，却很少想象自己也能亲手创造一点什么。那部电影并没有教我写代码，但它松动了心里的一个前提：为什么一定要等到"完全懂了"，才允许自己开始？

**"粗糙"是作品的现状，不应成为好奇心的边界。**

## 第二章｜第一个区块，第一枚牛币

接下来的几天，我把自己埋进代码。不断提问、运行、报错、修改、再运行。AI 帮我梳理陌生概念，也会生成需要我重新核对的答案。从网络配置到节点运行，从账户、私钥到挖矿和钱包界面，原本遥远的概念慢慢落在电脑屏幕上。

当实验网络第一次出现挖出的区块和奖励时，我非常兴奋。我很清楚，这些实验中的 NIU 没有可验证的市场价格，不能拿去买一杯咖啡。可那一刻，看到自己搭建的系统在规则内产生第一个奖励，我依然满足。

这份激动不需要币价作证明。孩子画出的第一张画、爱好者写成的第一个程序、第一次点亮的电路，都可能只有创造者明白其中的重量。对于世界而言，它只是一个小实验；对于曾经不敢接触区块链的我而言，它证明我已经走进了门内。

> 需要特别区分：仓库中已验证的第一个奖励区块属于集成实验网络，正式网络尚未启动。未来若设立正式网络，创世配置和启动记录必须另行冻结与公开，不会将本机实验区块冒充正式主网首块。

## 第三章｜价值从哪里来？

为什么一个没有价格的数字如此令人兴奋？因为价值有不止一种维度。市场价格源自真实交易中的供需与预期；技术价值取决于是否解决问题；学习价值来自理解和能力的增长；情感价值则来自"原来我也做得到"的经历。四者之间没有自动兑换关系。

货币的历史从贝壳、金属到纸币与电子账户，反复讨论同一个问题：人为什么愿意接受某种价值符号？答案涉及稀缺、制度、流动性、可验证的权利以及社会信任。仅凭发行总量有限，不能推导出有人需要它；仅凭开源，也不能推导出网络已安全。

**我们可以按规则创造一枚币，却不能用代码命令整个社会赋予它价值。**

## 第四章｜牛链真正是什么

牛链不是在以太坊等现有网络上发行的同名 ERC-20 代币。它是基于 Core-Geth v1.12.23 修改的独立账户式区块链实验，网络参与者需要在相同创世区块、链 ID、网络 ID 与共识规则下运行完整节点。GitHub 负责公开源代码与安装资料，而不是区块链服务器。

### 4.1 账本、签名与状态

普通账户由 secp256k1 私钥控制，交易使用签名授权，并通过余额、nonce、Gas 等规则验证。区块引用父区块哈希，承诺交易、收据和执行状态；完整节点自行检查区块有效性，并依据累计有效工作量选择历史。显示"已发送"不等于"已确认"，重组也可能使已入块交易重新待确认。

### 4.2 工作量证明

项目当前采用 Ethash PoW。难度候选沿用 Ethash/EIP-100 的调整形状，以 42 秒时间桶调整难度，移除难度炸弹与叔块奖励，设计目标平均出块约 60 秒。目标并非固定出块保证；实际时间依赖算力、时间戳、难度下限和网络传播。低算力实验网络尤其容易受到优势算力和网络隔离影响。

难度关系：

- `a = max(1 − floor(Δt / 42), −99)`
- `D_next = max(131072, D + floor(D / 2048) × a)`

该设计仍需长期算力变化和深度重组模拟。

### 4.3 EVM 可编程性

牛链保留 London EVM / Solidity 合约执行能力。现有集成验证覆盖留言合约的部署、读取与更新。这证明实验中的合约执行路径，不构成对交易所、跨链桥、收益合约或新版本 EVM 全部兼容性的承诺。

## 第五章｜NIU 的发行规则

以下是已纳入修改后节点源码、用于集成网络 26261017 的发行规则，并非对尚未启动的正式公网发行状态作出声明。

| 项目 | 规则 |
|---|---|
| 原生资产 | 牛币 NIU |
| 集成实验链 ID / 网络 ID | 26261017 |
| 创世分配 / 创始人预留 | 0 / 0 |
| 初始区块补贴 | 每有效普通区块 1000 NIU |
| 减半周期 | 每 1,050,000 块 |
| 基础精度 | 18 位小数 |
| 叔块及叔块奖励 | 不启用 |
| 理论基础补贴累计 | 约 2,100,000,000 NIU，实际因整数舍入略低 |
| 目标平均出块 | 约 60 秒，非固定承诺 |

令 `U=10^18`、`H=1,050,000`，创世高度 `h=0` 时 `R(0)=0`；当 `h≥1`，区块基础奖励以最小整数单位计算：

```
R(h) = floor((1000 × U) / 2^floor((h − 1) / H))
```

第 1 至 1,050,000 块各奖励 1000 NIU，下一阶段各奖励 500 NIU。发行总量因整数舍入略低于 21 亿 NIU，并不会为补齐差额而额外增发。

手续费另行计算：London 规则下基础费用销毁，矿工小费是现有 NIU 的转移，不计入新增基础发行。零创世预分配不能保证参与绝对公平，算力和入场时机仍可能形成差异。

## 第六章｜把链交到普通人手里：Windows 钱包

NIU Wallet 使用原生 Windows 图形界面，提供概览、发送、接收、交易记录、挖矿、智能合约、备份与设置。支持简体中文、英语、日语、韩语、西班牙语、俄语六种界面语言。可创建多个本地账户、收款二维码、地址簿，并主动开启或停止挖矿；程序不默认自动挖矿。

运行密钥目前依赖 Windows DPAPI CurrentUser 保护；钱包另有口令门禁、空闲约五分钟自动上锁，但口令门禁不等于密钥本身已由该口令派生的加密密钥保护。可以导出经密码加密的 V3 keystore 格式备份；目前备份覆盖当前全部自有账户（最多 32 个），不包含完整区块链历史、交易记录和联系人配置。新增地址以后必须重新备份，私钥和密码丢失无法由开发者恢复。

## 第七章｜去中心化，是一种需要证明的过程

一台电脑上运行两个独立节点，可以验证某些同步与转账逻辑，却不能证明网络已经去中心化。多台真实设备、公网可达入口、独立运营节点、链重组压力测试，才逐渐构成更有意义的安全证据。

仓库当前支持本机双节点和显式配置的朋友互联模式；尚未完成两台实体电脑公网互联验收，也未部署成熟的公共节点发现或 DNS 种子网络。网络连接不上传私钥，管理接口保持本机访问，但使用者仍需保护电脑与备份。

## 第八章｜AI、数字货币与十年后的可能性

假如没有 AI，几天内从零摸索一个完整实验，对我会困难得多。AI 降低了学习、阅读代码、定位错误的门槛，却没有取消核验的必要。它能帮助生成实现方案，不能替代严谨的共识测试与安全审查。普通人获得了更低的创造门槛，责任也因此更加直接。

### 8.1 可编程支付

未来数字资产可能与合同条件、机器服务和自动结算结合。AI 智能体之间的按次数据调用、计算资源与小额支付，是值得研究的方向；这些需求是否必须借助公链和独立 NIU，还需要实际成本与安全性比较。

### 8.2 资产表示与信任

现实资产的代币化可能改善某些记录与转移流程，但链上代币不能自动代替法律产权。加密签名能够证明某个密钥授权，并不能单独证明链外身份与事实。未来竞争的关键可能是制度、协议和用户体验之间如何衔接。

### 8.3 人人能造币之后

当创建区块链变得像制作网站一样容易，稀缺的可能不再是"会不会发币"，而是能否提出值得解决的问题、建立可持续的协作与可信运行机制。牛链希望先成为一座可以拆开观察的实验室：既让普通人看见技术如何运作，也让代码面对公开质疑。

## 第九章｜开源、共同研究与路线

牛链的开放方向是邀请爱好者共同研究 PoW、钱包工程、交易确认、智能合约、AI 辅助开发与系统安全。当前代码已在 GitHub 公开，基于 Core-Geth 的上游版权与许可证需要持续遵守。所谓"手搓"，指个人在既有开源技术和 AI 辅助下搭建、修改、集成与验证，并非声称凭空原创了密码学协议或整套节点代码。

后续研究方向包括：完成实体电脑互联及离线恢复验收、长期难度与重组模拟、独立安全审查、构建与签名发布、改进备份和密码学保护、公开可复核的正式启动参数。未来也可以探索 AI 智能体支付实验，但不会将构想写成已上线产品。

## 终章｜写给那个曾经只敢旁观的自己

最初，我只是看了一部画面粗糙的电影。它让我产生一个近乎荒唐的想法：别人能够把一件并不完美的作品做出来，我为什么不能尝试做出自己的数字货币？于是，我花了几天，和代码较劲，也和自己的无知较劲。

第一个奖励区块出现时，没有掌声，没有交易行情，没有人许诺它将改变世界。屏幕上只有几行字符，一枚暂时没有市场价值的币。可那份快乐是真的。它把"我好像不懂"变成了"我可以继续学"。

也许 NIU 永远不会拥有市场价格，也许它的代码还会经历无数次推倒重来。但只要有人通过它第一次理解区块、私钥、交易、挖矿与共识，或第一次把 AI 当作学习伙伴完成自己的程序，这段探索就留下了值得记录的经验。

**"我无法用一个区块证明未来，但这个区块足以记录我曾经开始。"**

如果你喜欢数字货币，也喜欢 AI，欢迎一起研究、提问、挑错，甚至重写它。愿我们先享受探索的乐趣，再用耐心与证据回答未来。
