# NIU Wallet v0.4.0 个人多链收发版

入口：Windows 完整目录内的 `NIU Wallet.exe`，侧栏「个人多链」。原 NIU 功能仍在原页面。

## 支持范围

- Bitcoin 主网原生 SegWit 单地址账户（bc1q）；Bitcoin Testnet 测试网络（tb1q）。
- Ethereum 主网 ETH、官方 ERC20 USDT、官方原生 USDC。
- Dogecoin 主网 DOGE（P2PKH，D 开头地址）。**Dogecoin 没有可用的公开测试网服务，本版只提供主网。**
- Sepolia 测试网 ETH、Circle 测试 USDC。不支持 TRC20、闪兑、法币购买、跨链、托管或理财。
- 余额、收款地址与二维码、预览网络/完整收款地址/金额/最高手续费、口令解锁后本机签名与广播、本机发送记录及链上状态查询。
- 本机发送记录不是完整的入账索引；入账请刷新余额并在对应链浏览器核对。

## 测试网与测试币（本版支持哪些）

切到页面顶部「测试网 · 测试币」标签，一共三张卡：

| 卡片 | 网络 | 币 | 水龙头（免费领测试币） |
| --- | --- | --- | --- |
| ETH | Sepolia 测试网 | 测试 ETH | `sepoliafaucet.com` 或 `faucet.sepolia.dev`，部分要 GitHub/Google 登录 |
| USDC | Sepolia 测试网 | Circle 测试 USDC | `faucet.circle.com`，选 Sepolia |
| BTC | Bitcoin Testnet | 测试 BTC（tb1q 地址） | `coinfaucet.eu/en/btc-testnet` 或 `bitcoinfaucet.uo1.net` |

三点要说清楚：

1. **Sepolia 的 ETH 和 USDC 是同一个地址**，就是那张 EVM 地址，领了测试 ETH 才有 gas 去转测试 USDC。
2. **DOGE 没有测试网**。Dogecoin 官方的测试链长期没有公开可用的区块浏览器与接口服务，所以本版只做 DOGE 主网，测试网标签里没有狗币。
3. 测试币没有任何价值，也不能换成真钱。领不到币时先刷新一次余额确认地址没填错；水龙头普遍限流，隔几小时再试通常就好了。

主网和测试网的**地址格式不一样**：主网 BTC 是 `bc1q…`，测试网是 `tb1q…`，两者互转会直接失败——这是保护，不是 bug。

## 界面结构（一币一卡）

顶部是「主网 · 真实资产」和「测试网 · 测试币」两个切换标签（带卡片数量），点一下即可切换，不必向下滚动找。每个币一张独立卡片：

- 卡片头：币标、币种符号、网络全名、主网/测试网徽章；测试网卡片为虚线边框加浅琥珀底色。
- 币标用官方矢量图：构建时从 `cryptocurrency-icons`（CC0-1.0 公有领域）取出 BTC / ETH / USDT / USDC / DOGE 的圆形图标，内联生成 `public/coin-icons.js`，页面直接用内联 SVG 绘制，运行时不请求任何网络、也不加载外部图片文件。要重新生成执行 `node tools/build-coin-icons.mjs`，放大看效果执行 `node tools/preview-coins.mjs`。
- 卡片体：余额（未查询时显示「未查询」，查询后显示数字与单位）、该网络收款地址与复制按钮。
- 卡片底：转出 / 二维码 / 刷新三个按钮。二维码、转出表单都在本卡内展开，互不影响；刷新只查该卡所属网络，同一网络的其它卡片共用结果。
- 顶部「刷新全部余额」按网络串行查询，避免并发触发后端占用。

## 首次使用

1. 正常退出旧版钱包。完整打开新版，不要只复制 EXE。
2. 进入「个人多链」，设置至少12字符的独立口令，创建账户。此处的新账户不继承旧 NIU 地址。
3. 再输入口令，点击「导出加密备份」，确认 JSON 已保存。备份含 BTC 密钥（DOGE 地址由同一把 BTC 密钥派生，不需要单独备份）和 EVM 密钥，旧 NIU 账户需要在原设置页面另外备份。
4. 建议先用测试网卡片练手：复制卡片上的 tb1（BTC 测试网）或 Sepolia 地址去水龙头领测试币，点卡片「刷新」看到余额后，再试转出。测试币没有价值，转错不心疼。
5. 主网卡片显示的是真实资产地址。Ethereum 卡片的地址同时接收该网络的 ETH、USDT、USDC，不能接收 Tron TRC20 提币。Dogecoin 只认 D 开头的地址，把 BTC 地址填进去会被拒绝。
6. 转出 ERC20 稳定币需预留 ETH。BTC / DOGE 仅花费已确认UTXO，首版最多40个输入，不提供发送全部或自定义费率。
7. 点击卡片内「预览金额与手续费」后核对网络、金额、手续费与完整地址。输入「确认主网发送」或「确认测试网发送」，再点「签名并发送」。预览90秒失效。

## 安全与恢复

个人保险库 `personal-multichain/personal-vault.json` 位于原应用链数据目录内，使用独立口令的 scrypt + AES-256-GCM。升级不覆盖原 `wallet.dpapi`。5分钟无签名操作自动锁定。口令不可找回。

新备份格式 `niu-personal-vault` 与旧 NIU 备份分开；在另一台电脑/全新数据目录的「个人多链」导入。已有个人账户时拒绝覆盖。恢复后务必核对 EVM、BTC 主网、BTC 测试网、DOGE 四个地址。

节点服务：Ethereum / Sepolia 默认使用 PublicNode JSON-RPC；Bitcoin 主网/测试网使用 Blockstream Esplora；Dogecoin 使用 BlockCypher。查询会披露该地址给服务商，私钥不会发给服务商。第三方节点可能限流、不可用或提供错误数据，首版未实现独立SPV或多节点共识校验。

广播前将已签名交易和本地哈希落盘。广播结果未知时保留记录并阻止同网络再次转出；刷新可恢复状态，不自动重发。若节点持续查不到交易，请保留备份与记录后人工检查，不能把“查不到”当作“没发出”。BTC/DOGE/ETH 首次上链即显示已确认，不代表不可重组的最终性；请在浏览器核对确认深度。

## Dogecoin 专章

- 地址为 P2PKH（D 开头），与 BTC 使用同一把派生密钥但**地址格式不同、不能互换**。把 bc1q 地址填进 DOGE 卡片会被直接拒绝，反之亦然。
- 费率取自 BlockCypher 返回的 `medium_fee_per_kb`，按 1 DOGE/kB 向上取整，再按「10 + 148×输入数 + 34×2」估算字节数。
- 两个硬性保护：单笔金额低于 **0.01 DOGE** 直接拒绝（避免粉尘输出）；估算手续费超过 **5 DOGE** 直接拒绝（避免费率异常时被抽干）。命中任一条都会在预览前报错，不会签名。
- 交易用 `nonWitnessUtxo` + P2PKH scriptSig 构造，并放开 bitcoinjs 默认的 5000 sat/vB 上限（`maximumFeeRate`），否则 DOGE 的正常费率会被误判为异常。
- 只花费已确认 UTXO，最多 40 个输入；没有「发送全部」，没有自定义费率。
- 余额与未确认金额来自 BlockCypher 的 `/addrs/{地址}/balance`；发送走 `/txs/push`。第三方服务可能限流，遇到失败请稍后刷新，不要重复点击发送。

## 关于「转不出去」

收到币不等于马上能转出，遇到下面几条都属于设计内的保护，不是功能缺失：

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 已确认的 BTC 余额不足。另有 X BTC 还未确认… | 只花已确认 UTXO，刚到的钱还在内存池 | 等 1 次确认（约 10 分钟）再转 |
| 有 X DOGE 还未确认… | 同上 | 等 1 次确认（约 1 分钟）再转 |
| ETH 余额不足：当前可用 X ETH | 转 ETH 要金额加手续费一起够 | 少转一点，或先充 ETH |
| USDT / USDC 余额不足 | 代币够不够是分开算的 | 先刷新余额核对 |
| 无法估算手续费：通常是 ETH 余额不足以… | 转 ERC20 需要 ETH 付 gas，ETH 为 0 就会这样 | 往同一个地址充一点 ETH |
| 该网络已有待确认或广播结果未知的交易 | 同网络同时只允许一笔在途 | 先点「刷新」把上一笔状态确认掉 |

余额卡片上的数字是**已确认余额**；「刷新全部余额」会逐个网络查询，某个网络查不通时该卡片显示红色「查询失败」并把鼠标悬停可看原因，其余网络照常更新，不会因为一个网络挂了就全部停在「未查询」。

## 看不到「个人多链」怎么办

如果打开钱包后侧栏只有「概览 / 发送 / 接收 / 交易记录 / 挖矿 / 智能合约 / 设置」，说明**屏幕上那个窗口是旧版**，不是新版缺功能。

原因：钱包同一时间只允许运行一个实例。旧版还开着的时候双击新版，新版会立刻自己退出，系统把旧窗口调到前面——看起来就像「新版没有这个功能」。

处理办法：

1. 在任务管理器里结束所有 `NIU Wallet.exe`（旧版可能还挂在托盘里）。
2. 确认启动的是 `D:\NIU-Wallet-v0.4.0-Windows-x64\NIU Wallet.exe`，不是桌面或开始菜单里指向旧目录的快捷方式。
3. 新版侧栏左下角会显示 `版本 0.4.0`。看不到这行字就是旧版。

v0.4.0 起，被单实例拦下时会弹窗明确提示，不再静默退出。
