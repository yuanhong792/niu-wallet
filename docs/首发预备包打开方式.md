# 首发预备包打开方式

这是 Windows x64 的桌面钱包，主程序为 NiuWallet.exe，使用原生 Windows Forms 窗口，不需要浏览器。

1. 完整解压 NIU-Wallet-0.3.3-owner-review-win-x64.zip。
2. 打开解压后的文件夹，双击 NiuWallet.exe。保留 engine、bin、assets、scripts、node_modules 等同包组件，不要只复制一个EXE。
3. 首次启动时由你选择创建自己的钱包或恢复加密备份。程序包不含开发者钱包、链数据库、私钥或余额。
4. 当前首发预备包为本机集成网络，默认不挖矿，不连接公网，不属于正式首发链。请先检查界面、地址、二维码和备份。

你希望亲手挖出正式第1个奖励区块，须等正式网络配置与发行验收冻结后执行；不要把这个预备包上的区块称为正式首块。具体顺序见“首发与第一区块”。

源码可以公开，当前 ZIP 仅在你的本机提供，没有上传 GitHub Release。完整软件包含后台 Node.js 与牛链节点；这是带本地节点的桌面钱包，并非单文件安装器。
